# SIH26182 — Unified Interface Contract

This document defines the authoritative JSON interface contract shared across **Data/ML**, **Backend**, and **UI** modules for wallet attribution responses.

---

## JSON Schema

```json
{
  "wallet_address": "string",
  "risk_score": 0.0,
  "risk_label": "illicit / licit / uncertain",
  "graph_hops_to_nearest_vasp": 3,
  "nearest_vasp_name": "string or 'unidentified'",
  "attribution_confidence": "high / medium / low",
  "top_features": ["feature1", "feature2", "feature3"]
}
```

---

## Field Specifications

- `wallet_address` (*string*): The unique on-chain cryptocurrency wallet address queried (e.g., Ethereum hex `0x...` or Bitcoin base58/bech32).
- `risk_score` (*number / float*): Normalized risk probability score from `0.0` (safest) to `1.0` (highest risk) generated by the attribution model.
- `risk_label` (*string*): Categorical classification outcome restricted to `"illicit"`, `"licit"`, or `"uncertain"`.
- `graph_hops_to_nearest_vasp` (*integer*): Shortest topological graph path distance (in transaction hops) connecting the wallet to a known Virtual Asset Service Provider (VASP).
- `nearest_vasp_name` (*string*): Canonical name of the nearest recognized VASP entity (e.g., `"Binance"`, `"Coinbase"`, `"Tornado Cash Mixer"`), or `"unidentified"` if no entity is resolved within search bounds.
- `attribution_confidence` (*string*): Model and heuristic attribution certainty level restricted to `"high"`, `"medium"`, or `"low"`.
- `top_features` (*array of strings*): Ranked list of primary human-readable graph and behavioral features that influenced the attribution score.
